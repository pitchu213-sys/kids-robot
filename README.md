# 🤖 روبوت الأطفال التفاعلي الذكي (Kids Robot)

مشروع روبوت تفاعلي ذكي للأطفال يعتمد على مبدأ **"التوأم الرقمي وتجربة المستخدم أولاً"**، حيث تم بناء واختبار تجربة الطفل والقصص التفاعلية والذكاء الاصطناعي والصوت بالكامل على الهاتف والمحاكي قبل الانتقال لتجميع وبرمجة العتاد الفعلي على شريحة **ESP32-S3**.

---

## 🌟 الهيكل العام للمشروع

```
kids-robot/
├── simulator/             # التوأم الرقمي وتطبيق الهاتف (PWA)
│   ├── index.html         # شاشة الروبوت الدائرية (GC9A01 240x240) وحلقة 12 LED
│   ├── robot.css          # مؤثرات الإضاءة والرسوم والتصميم الملائم للهاتف
│   ├── robot.js           # محرك تعبيرات الوجه، الصوت العربي، وحساس اللمس
│   └── manifest.json      # ملف تثبيت التطبيق على الشاشة الرئيسية للهاتف (PWA)
├── backend/               # سيرفر التحكم والذكاء الاصطناعي (Python FastAPI)
│   ├── main.py            # سيرفر WebSockets والأوامر الموحدة
│   ├── requirements.txt   # متطلبات التشغيل
│   └── stories/           # القصص التفاعلية المقسمة لمقاطع (JSON)
│       ├── space_adventure.json
│       └── forest_friends.json
└── esp32_firmware/        # كود C++ لشريحة ESP32-S3 (المرحلة القادمة)
```

---

## 📱 تجربة تطبيق الهاتف مباشرة (عبر GitHub Pages)

1. فعّل **GitHub Pages** من إعدادات المستودع (Settings -> Pages -> Branch: `main` / Folder: `root`).
2. افتح الرابط الناتج على هاتفك عبر متصفح **Chrome** أو **Safari**.
3. اضغط على خيارات المتصفح ثم اختر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. سيتحول هاتفك بالكامل إلى روبوت حقيقي للأطفال:
   * **اللمس:** المس الشريط العلوي "المس رأسي" للتفاعل (يدعم الاهتزاز الحركي Haptic).
   * **الصوت:** اضغط زر "تحدث معي" ليرد عليك الروبوت ويفهم كلامك بالعربية.
   * **الإضاءة والوجه:** شاشة دائرية 240×240 حقيقية محاطة بـ 12 نيو بكسل LED ملونة.

## 🔌 بروتوكول الأوامر الموحد (Unified Protocol)

يتعامل السيرفر مع كل من **المحاكي (تطبيق الهاتف)** و **شريحة ESP32-S3** بنفس صيغة البيانات بالضبط عبر WebSocket:

```json
{
  "event": "STORY_CHUNK",
  "face": "happy",                         // تعبير الوجه: happy, wonder, curious, love, sleepy
  "led": { "pattern": "spin", "color": "#00f2fe" }, // حلقة 12 LED
  "text": "مرحباً يا بطل! هل أنت جاهز؟",     // النص المنطوق
  "action_required": "wait_touch",         // انتظار اللمس أو الصوت
  "hint": "المس رأسي للانطلاق!"
}
```

## 🚀 تشغيل السيرفر محلياً أو على GitHub Codespaces

```bash
cd backend
pip install -r requirements.txt
python main.py
```
السيرفر سيعمل على المنفذ `8000`، ويمكن للهاتف الاتصال به عبر إدخال عنوان الـ IP من لوحة الإعدادات الجانبية.
