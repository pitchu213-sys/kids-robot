# 🤖 روبوت الأطفال التفاعلي الذكي (Kids Robot)

مشروع روبوت تفاعلي ذكي للأطفال مبني على معمارية **فصل العرض عن العقل (Face & Brain Architecture)**:
1. **تطبيق وجه الروبوت (`index.html`)**: مخصص للطفل ولشاشة العتاد (GC9A01 240×240 و 12 LED)، شاشة نقية بدون أي تشويش.
2. **تطبيق عقل الروبوت (`brain.html`)**: لوحة الأهل والتحكم لإدخال بيانات الطفل، كتابة التوجيهات لينطقها الروبوت فوراً، التحكم بالمشاعر، وإدارة القصص.

## 📂 هيكل المشروع

```
kids-robot/
├── simulator/
│   ├── index.html       # (1) شاشة وجه الروبوت النقي للطفل (GC9A01 240x240 + 12 LED)
│   ├── robot.css        # مؤثرات الوجه والعيون الكرتونية وتوهج الإضاءة
│   ├── robot.js         # محرك تعبيرات الوجه والصوت ومستقبل أوامر العقل
│   ├── brain.html       # (2) تطبيق عقل الروبوت ولوحة الأهل (Dashboard)
│   ├── brain.css        # تصميم لوحة العقل
│   ├── brain.js         # محرك بث الأوامر والتحكم الحي
│   └── manifest.json    # ملف تثبيت التطبيق على الشاشة الرئيسية (PWA)
├── backend/             # سيرفر Python الموحد للأوامر والذكاء الاصطناعي
│   ├── main.py          # توجيه الأوامر بين العقل والوجه والـ ESP32
│   ├── requirements.txt # متطلبات التشغيل
│   └── stories/         # القصص التفاعلية الذكية
└── esp32_firmware/      # كود C++ لشريحة ESP32-S3 (مرحلة الهاردوير)
```

## 🔌 بروتوكول الأوامر الموحد

يتواصل تطبيق **عقل الروبوت** مع **وجه الروبوت** ومع **لوحة ESP32-S3** بنفس صيغة الـ JSON تماماً:
```json
{
  "event": "SAY_TEXT",
  "text": "يا بطل، حان وقت النوم!",
  "face": "sleepy",
  "led": { "pattern": "pulse", "color": "#a855f7" }
}
```
